# makrov

주석처리매크로

makrov.py와 같은위치에 주석처리할 파일을 넣고

COMMAND_NAME_ARRAY에 주석처리할 명령어
FILE_NAME_ARRAY에 주석처리할 파일이름
넣고 실행하면 됩니다.
